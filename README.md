# 11gal 企划

《11gal》系列 galgame 的企划文档仓库。

> 本仓库当前只同步 `企划/` 目录；剧本、工具、调研等其他内容暂未纳入。

## 文件怎么分

### 📖 通用阅读：快速了解世界观与人物

想快速了解这个世界观和人物，**按序号顺序看这几份就够了**：

| 文件 | 作用 |
|---|---|
| `00-系列总览.md` | 系列定位、主题、基调、作品形式——先看这个建立整体印象 |
| `01-世界观.md` | 核心世界观：西湖大学=SCP 基金会研究所、保密机制、已知真相的学生、收容物 |
| `05-世界设定.md` | 11 项世界设定表：时间 / 地点 / 社会系统 / 世界法则 / 通信等 |
| `02-角色池.md` | 全员总览：男主 + CBT + 10 位已知真相的学生 |
| `06-角色设定表.md` | 男主、CBT 的 13 字段详细设定 |
| `07-角色设定表-强者.md` | 6 位重点角色的 13 字段详细设定 |
| `11-角色速查卡.md` | 角色性别 / 年级 / 称呼 / 口癖速查（写场景前也要先读这份） |
| `18-异常分类与角色身世档案.md` | 官网体系对接 + 角色身世档案（深入背景，入门可先跳过） |

### 🧭 指导文件：怎么往下做（第一步）

这些不是“设定”，而是**“怎么做”的过程文件**——开始写剧本或继续创作时，按这个顺序看：

| 文件 | 作用 |
|---|---|
| `04-企划表.md` | 企划表：主题、故事推导链、序破急、引子 |
| `03-第一部-结构.md` | 第一部（CBT 线）结构与事件链 |
| `13-序破急与节奏分析.md` | 写作时定位当前场景在整条节奏线的哪个位置 |
| `10-语言风格设计-剧本用.md` | 写任何角色台词前先看：辨识锚点 + 口癖 |
| `08-场景01-序章与招新-设计定稿.md` | 场景 01 设计定稿 |
| `09-场景02-侦探社成立-设计定稿.md` | 场景 02 设计定稿 |
| `12-场景03-物理实验课-设计定稿.md` | 场景 03 设计定稿 |
| `14-场景04-快递柜案-设计定稿.md` | 场景 04 设计定稿 |
| `15-场景05-走廊脚步声案-设计定稿.md` | 场景 05 设计定稿 |
| `16-场景06-爬塔联机-设计定稿.md` | 场景 06 设计定稿 |
| `17-场景07-番茄案-设计定稿.md` | 场景 07 设计定稿 |

> **一句话总结**：了解设定看「通用阅读」；动手写剧本看「指导文件」。
