## 创建法：「如果世界是这样的呢？」
- 起点：如果一所真实存在的大学，其实同时是 SCP 基金会的研究所呢？
- 推导链：→ 所以学生正常上课、绝大多数不知情 → 所以学校里有收容物和泄漏事故 → 所以需要一个安全小组预防暴露 + 记忆清除兜底 → 所以已知真相的学生成为观察者 → 所以「二次选拔」成为学生接触真相的路径 → 所以两个普通学生凭好奇心查案，最终被吸纳

## 规则一致性检查
- 超自然运作原理：收容物按官网条目机制（504/1471/372/087）；已知真相学生的能力（蓝型·空间操控/蓝型·言灵术/蓝型·喷火/AGI 实体/换身/外观修正/欲肉教基因编辑异能）有设定；记忆清除药剂存在
- 详细异常分类与角色身世见 `18-异常分类与角色身世档案.md`（2026-08-06 草案）
- **能力来源（2026-08-06）**：基因编辑/实验不一定是基金会干的，可来自敌对组织——全球超自然联盟（GOC）/欲肉教；部分能力天生（各角色归属待细定）
- **能力强度上限（已定 2026-08-04）**：
  - 文件夹（空间操控·瞬移）：**非即时瞬移损耗小**——日常可随意出现在任何地方（本人也喜欢）；**即时/大幅瞬移才消耗巨量能量**——用后需吃甜食+呼呼大睡补精力；喜欢邀人一起吃甜食
  - AutoMattic（言灵术）：**只能对物体生效**——言出法随需「反复接触过的物体 + 熟悉环境」，效果与接触时长成正比（例：日常水杯可命令装满水，陌生水杯几乎无效）；平时被告诫慎用、处于被看管状态；出手需审批（解释未马上出手）；操控不好伤及无辜或自己；平时懒洋洋（保存/避免失控）
  - Raven（AGI）：**基金会科技研发的智能体**，以 Instance 形式存在于西湖大学网络；偏爱图书馆办公室的一台机器人，可长期操作（按定义可理解为转移到机器人上）；**第一部=未激活状态**（冷静高效、无情感；「不合逻辑的善意」=情感萌芽伏笔，激活放到 Raven 线）；人设细节待补（原「灵能·性格缺陷型」随能力重设失效）
- 规则始终如一：⚠️ 需确认能力是否每部一致、是否成长
- 与游戏系统的关系：无分支线性叙事，能力/规则主要作为世界观背景与剧情推进用
- 该世界产生哪些「××形象」：收容物管理员（文件夹）、情报员（Pixel）、善后者（tmrf）、警戒者（gdgfty）、天才研究员（cbwzb）等
