# 角色设定表（13 字段）

## 男主

| # | 字段 | 内容 |
|---|---|---|
| 1 | 名字 | 玩家自选 ID |
| 2 | 年龄 | 18-19（2026 级新生） |
| 3 | 职业 | 学生（西湖大学，不分专业） |
| 4 | 相貌 | 普通相貌 |
| 5 | 头发 | 黑色 |
| 6 | 体格 | 比较高瘦 |
| 7 | 服装 | 西湖大学 T 恤 + 牛仔短裤；习惯：校园卡挂脖子上（新生标志） |
| 8 | 性格（含成因） | 路痴（认不出建筑）、社恐但硬上、爱游戏、创新/开拓精神、自嘲式记账、36 小时作息 |
| 9 | 定位型性格 | 成长型主角 |
| 10 | 特技 | 游戏（杀戮尖塔/剧本杀）、推理小说阅读量 |
| 11 | 弱点 | 路痴、社恐 |
| 12 | 口吻 | 旁白第一人称「我」；心理活动全角括号；自嘲式记账（如「方向感输给了我，我赢了快递柜」）；**无固定口头禅，语言自然** |
| 13 | 剧本上的设定 | 新生 → 侦探社员 → 第一部：加入研究所 → 编外调查小组 |

**角色定位**：系统相关（主人公）；变化（成长/契机——从社恐新生成长为调查者）
**个人层面的理由**：推理爱好者被「未解之谜」吸引 + 被挽留 + 想证明自己能行（成长动机）
**台词示范（草稿，供校准口吻）**
| 情境 | 台词 |
|---|---|
| 初见 | 「这个『校园未解之谜调查部』……都查些什么？」 |
| 生气 | 「路线错成这样，也不能全怪高德地图。」 |
| 高兴 | 「线索对上了。这把算是我们赢的。」 |
| 悲伤 | 「线索又断在半路……至少这次知道该往哪儿查了。」 |
| 紧张 | 「先冷静。我看这楼梯对不对——先记下来，回头再对。」 |

## CBT.свт（CBT）

| # | 字段 | 内容 |
|---|---|---|
| 1 | 名字 | CBT.свт（CBT） |
| 2 | 年龄 | 外表固定（**萝莉体型**，不会长大=装帧锁定）；**图书馆「活书」**；**大二学姐**（苏醒后入学，已普通度过大一一年） |
| 3 | 职业 | 学生（本质：图书馆的「活书」） |
| 4 | 相貌 | **白毛萝莉红瞳**；眼睛比较大 |
| 5 | 头发 | **白色（白发）** |
| 6 | 体格 | **小萝莉**（身体固定=装帧锁定，不会长大） |
| 7 | 服装 | 日常普通卫衣；**哥特式服装 = 苏醒时穿的服装**（旧时代/图书馆气质），平时不拿出来，只在自认为严肃的场合穿（类似战斗服装） |
| 8 | 性格（含成因） | 正义感强、好奇心强；**情感稚嫩、迟钝，像小孩一样**（理智发展过强=「书在学做人」）；刚苏醒、不懂现代生活；线上活跃线下社恐；**分析问题强、联想能力强（思维宫殿）** |
| 9 | 定位型性格 | 队长般（组织者/行动发起人）；谜之少女（身世之谜核心） |
| 10 | 特技 | **强大计算能力、思维宫殿推理**；分析问题、联想能力、线上社交；**监听小工具（侦探取证装备，图书馆偷听/黑内网用）** |
| 11 | 弱点 | **情感稚嫩/迟钝（像小孩）**、线下社交、现代生活常识缺失（刚苏醒） |
| 12 | 口吻 | 短句快节奏（源样本 75% 短句、中位 11 字）；判断前置+转折推进（口癖池 v2：绷不住了/这对吗/但是·所以）；游戏梗多（鸡煲/观者等）；直接吐槽、快速纠正；线上聊天碎片化、线下更简短；**情感表达直接、带小孩式的稚嫩** |
| 13 | 剧本上的设定 | 图书馆转化完成（「活书」）→ 苏醒 → 迷茫时收到西湖大学录取通知书 → 入学 → **普通度过大一一年、仍未查清自己的情况** → 大二**借创立侦探社的机会同时探索身世之谜** → 第一部女主 → 加入研究所 → 编外调查小组 |

**角色定位**：系统相关（待攻克对象）；同阵营（情侣）；变化（契机——发起侦探社推动全案 + 身世之谜）
**个人层面的理由**：好奇心 + 正义感（看到怪事想管）+ 想解开自己的身世之谜；情感像小孩、线下社恐，所以选择线上发起侦探社
**台词示范（草稿，供校准口吻）**
| 情境 | 台词 |
|---|---|
| 初见 | 「你是刚才频道里那个吧？你好。」 |
| 生气 | 「离谱。但排除不了。」 |
| 高兴 | 「第一单，结案！」 |
| 悲伤 | 「……先挂着吧。没证据的事，我不说。」 |
| 紧张 | 「……你听到了吗？」 |
