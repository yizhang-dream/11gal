## 事件链
### 0. 前两案（侦探社第一次行动）【定稿 2026-08-05】
- **背景**：侦探社成立时就有两条挂起的委托（快递柜稿=机器人搜集；走廊脚步声稿=口头私下告诉 CBT）
- **快递柜案（第一单）**：H3 门口碰面（**男主和 CBT 第一次线下见面**）→ 经食堂后面电梯到 **H5 地下一层快递柜**——有人快递「不见了」，实地查发现其实是被**更大的箱子压住、看不见** → 查清（普通解释）
- **走廊脚步声案**：目击者半夜取外卖听到脚步声、走廊没人、找了一圈没有 → 深夜 H3 蹲点查不出 → **CBT 思维宫殿法**推理锁定**洗衣房** → 靠近真的听到「脚步声」→ 男主「社长大人别怕，我先上！」挥平板开门 → 没人 → **水龙头没拧紧、一直滴水** → 查清（普通解释）
- **结果**：两案查清，初战两连胜；两人组默契确立（小序破急见 `企划\13`）

### 1. 番茄案（SCP-504）【定稿】
- **受害者 = HAL**（CBT 好友，战斗苗子，未完成培训、不知基金会内情）：在食堂吃饭时被番茄炒蛋糊脸（她自己讲了烂梗→盘中番茄弹起，但她以为是有人推的）；很气愤但社恐没闹大、没锁定人
- HAL 线上（群聊）向好闺蜜 CBT 分享悲惨遭遇 → **CBT 决定查**（好友受害 + 正义感/好奇心）→ 拉男主一起，侦探社第一个熟人委托
- 按「找恶作剧者」排查嫌疑人 → 追查很久无果
- 调监控（CBT 以侦探社名义申请；**保卫处=表面普通保卫处、实际基金会安全小组外勤伪装层（gdgfty 挂名）**，值班人员陪看但心不在焉=内部解释：知道学生查不出名堂）：画面跳帧——上一秒在桌上、下一秒糊 HAL 脸上，中间无帧 → CBT 思维宫殿三假设（监控被抽帧=内鬼 / 有人瞬移 / 飞太快没拍到）→ 查「是否被改」无权限 → 挂起；CBT 心里怀疑内鬼但不直说（**注：此时侦探社不知道有人会瞬移，「瞬移」只是开脑洞假设，不指向任何人**）
- HAL 因不知情不会警觉/阻止（保持「已知真相的学生不出手」逻辑）
- **火锅聚餐收尾**：H4 楼下集合（HAL 线下初见：社恐话少冷幽默）；Pixel 量子力学劝退；HAL 拒番茄汤底笑点；番茄案正式挂起
- **收尾**：番茄不需「解决」——实验田泄漏的少数番茄流到食堂，结尾解释同源泄漏后**严加看管**，不再有新番茄

### 2. SCP-1471 案【已定·弱化版】（方案 C：半断有获）
- 大群有人发现手机多了个 App，**卸载不掉**；他懒得重装系统，打算过几天再重装（喜剧细节）
- 群里提醒同学们不要下载来路不明的软件
- 侦探社好奇为什么会有这样的软件 → 发起研究
- 研究过程中，越来越多的同学「感染」这个软件，事情逐渐放大
- **断点**：受害者不配合 → 查不清楚
- **关键线索（方案 C：侦探社不是纯被动）**：CBT 用技术手段顺着 App 的数据连接追——发现数据终点指向**校园内网深处一个加密节点**，权限不够，只能看到它属于某栋楼的内部网络，再往里一片漆黑 → **侦探社第一次意识到「学校里有一个他们碰不到的内网世界」**（学校秘密第一块碎片；也为 CBT 后来的黑内网预演路径）
- **生物设定（修改）**：MalO 实体已被研究所收容过一次，现在很弱、无法跟踪人；但 **App 独立运行**
- **软件设定（修改）**：App 只能发送照片，不能跟踪；照片里出现黑影（MalO 黑发狗头骨人形剪影，被改黑的一两张照片）
- 新谜团方向：实体被收容，App 为何仍在运行/传播【待细化】
- **解决**：AutoMattic（言灵术）**补最后一刀**，App 处理失效；随后有人通知侦探社「无需继续侦查」（**全剧唯一一次「无需侦查」通知**，有人插手的观感，悬念留到结尾解释）——但侦探社已把「内网深处」记在案

### 3. SCP-372 案【定稿】（方案 C：合/转折）
- 大群有人凌晨回寝室发消息：「好恐怖啊，总感觉好像走廊有东西」
- 本来以为是错觉，但没睡着的人纷纷表示曾有这种感觉（一两人）
- 侦探社判断：可能有嫌疑人正在从事不法行动（跟踪/偷窥方向）→ 按「查嫌疑人」查
- **查案过程**：
  1. 常规排查：问目击者 → 描述全对不上 → 查监控 → 拍不到人 → 线索断
  2. **蹲点抓现行**：CBT/男主自己余光瞥到一瞬，转头什么都没有——从「怀疑别人」变成「怀疑自己」，侦探社第一次动摇
  3. 目击地点汇总：宿舍区为主 + 个别目击出现在**图书馆附近** → 侦探社去图书馆查问（学校秘密第二块碎片的入口；不再直接指向 F11）
- **Raven 正面接触（方案 C：不再事后通知，改为当面）**：图书馆机器人主动搭话——自称科学爱好者，说「你们在找走廊里那个东西吧？我见过类似的……建议别往 F11 那边去」（给线索+警告）；**这个主动提示超出程序要求=「不合逻辑的善意」伏笔**（Raven 线解释）；随后 372 现象消失（已被 Raven 处理，目击者不再报告）
- 官网机制依据：372 只让被跟踪者看见、监控/普通视觉抓不到、有盲点不攻击（见文末附录）
- **解决**：Raven 出手处理 372（侦探社视角=机器人给了警告后怪谈自己消失了）；**无「无需侦查」通知**

### 4. 学校秘密的提前揭晓（087 之前）【2026-08-06 定】
- **位置**：372 案断点之后、F11 踩点/深入 087 之前
- **图书馆偷听（神秘人物钩子）**：侦探社追查 372 线索到图书馆，发现一间**需要电子锁的房间**，里面似乎有人在对话；CBT 用她的**监听小工具**偷听——一个女声问「那件事情查得怎么样了？」，另一个声音答得模棱两可（**答话者是谁，没看见**）。过了一会儿门突然打开，**gdgfty 从里面出来**，两人赶紧**假装路过**（她扫了一眼/平淡走开，侦探社事后不确定有没有被盯上）。→ **「神秘学姐」（gdgfty）进入关注名单**；「房间里还有谁」留悬念（玩家视角：她只是个不认识的神秘人物，结尾才点破=安全小组组长）
- **CBT 主动黑进学校内网**：偷听事件后 CBT 起疑，**主动**黑进校内网（她计算力强、本来就想查学校的秘密；**1471 时已摸过内网路径，这次顺藤摸瓜**），发现学校存在**秘密超自然研究计划**——权限不够，只看到细枝末节的泄露；其中物理系下有一个**空间相关研究计划**，她只看到研究对象的 **ID=文件夹**（看不到姓名/资料）
- **Raven 为什么被关注（依据=数据，不是目击）**：CBT 顺着图书馆那间电子锁房间查出入/设备日志——发现它与校园网里一个代号 **Raven** 的 **AI 实例** 有数据往来；侦探社把 372 案里自称「科学爱好者」的图书馆机器人与这个 AI 联系起来 → **Raven 进入关注名单**（关注的是「能操控机器人、藏在校园网里的 AI」与秘密房间的关系，**不是指认它干了什么**）
- **侦探社的推理链（重要，别写成「抓凶手」）**：四案证据（监控跳帧=学校里有内鬼 / 1471 App 在传播 / 372 有人跟踪）+ 黑内网发现学校有秘密超自然研究 → 侦探社推断：**这些怪事很可能就是学校秘密研究搞出来的、或与之相关**。但**没有任何一条证据证明具体是谁干的**——神秘学姐、文件夹、Raven 只是「与秘密组织相关的人/实体」，被列入**关注名单**（可能知道内情、可能相关），**不是「确定罪犯」**
- **认知升级**：此时仍不知道「基金会」——只知道**学校背地里在搞超自然研究**；侦探社的预设变成「学校有问题、在掩盖什么」（保密+跳帧+App 让这个预设合理），087 的反转=打破这个预设
- **注意（2026-08-06 用户明确）**：侦探社一开始不知道有人能瞬移、不知道基金会存在——怀疑依据只能是**内网泄露的 ID 与神秘对话**，不能是「瞬移」这类超能力
- **功能**：① 给「为什么敢深入 087」提供动机（门=学校秘密的可能答案，目的是**查证学校在搞什么**，不是抓现行）；② 文件夹救场=「以为学校在作恶 → 原来是保护性组织」的认知反转；③ 摊牌时「学校=基金会研究所」有前置铺垫，不是空降；④ **碎片拼接**：1471 的「内网深处」→ 黑内网的「秘密研究」→ F11 门=同一个世界的入口

### 5. SCP-087 案【定稿】
- **位置：西湖大学 F11 地下一层角落**
- 087 本来就在西湖大学（研究所选址的原因之一；「地基级异常」）
- **门为何暴露**：安全小组例行检查后忘记重新封好（人为疏忽；gdgfty 小组的失职钩子位）
- **深入流程**：
  0. **深入前 CBT 换上哥特服**（苏醒时的原始着装=「战斗服装」，动真格的信号；白毛萝莉+哥特装的视觉反差，男主第一次见）
  1. 372 目击点延伸至 F11 → 踩点发现未封好的门（结合黑内网信息：这可能就是学校秘密研究的入口）
  2. 深入：官网机制全上——黑暗（13 阶/38°/180°平台）、叫声引诱往下但永远无法接近、空间异常（台阶数对不上/手机无信号/光线受限）
  3. **087-1 出现**：无五官的脸浮出，两人强烈恐惧
  4. 恐惧中、文件夹现身**之前**，两人互相表达感情（高潮点）
  5. **文件夹从前方的黑暗中突然出现**（楼梯深处方向），吓他们一跳，随后救场
  6. 摊牌时闭环：黑内网看到的「空间研究计划 ID=文件夹」=她的超自然研究组课题（注册蓝型，研究自己）——关注名单里的人其实是自己人；「学校在搞坏事」的预设被打破
  7. 封印入口 → 解释四案同源（实验室泄漏）→ 摊牌（学校=研究所、被观察选拔）→ 选择加入

## 高潮
- 地点：087 楼梯深处（恐怖环境）
- **两人互相表达感情**（恋爱线收束）与真相揭晓在同一场景
- **CBT 情感稚嫩校准**：她在 087 里不会成熟告白，而是像小孩护住重要的人一样笨拙地表达「你很重要/别死」（理智侧已推出结论、情感侧只能说出最直白的话）
- 四案线索板全部闭环，挂起的憋屈感一次性释放
- 文件夹（空间系）救场；其余已知真相的学生已在背景出场

## 结局
- CBT 和男主加入研究所，**单独成立编外调查小组**（不跨线延续）
- **编外调查小组独立运作（不归安全小组管辖）**：gdgfty 结尾出现（交接、交代疏忽）；087 门暴露 = gdgfty 管理疏忽，结尾有交代；**图书馆那场「那件事情查得怎么样了」的神秘对话=gdgfty × Raven**（摊牌时点破：Raven 是研究所 AGI、gdgfty 是安全小组组长——幕后黑手感解除）
- **加入后放开权限 → 查到「当年 CBT 入学时与『蛇之手』组织的通信记录」**（身世暗线第一块实锤：录取通知书=蛇之手渠道送达）——只给钩子，**完整身世来源放后日谈**（2026-08-06 定）
- **tmrf 结尾在场**：文件夹救场时她已等候——若拒绝加入则清除记忆；加入后**陪同 tmrf 清除相关人员的记忆**（范围=普通学生：1471 受害者、372 目击者；**HAL 不清**——培训期新人=知道被选入特殊项目、不知基金会与异常真相，属内部序列）——善后第一课
