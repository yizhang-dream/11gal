# 企划 12：场景 03（物理实验课）设计定稿

> 来源：grill-me 访谈（2026-08-05）
> 结构：按 skill 序破急；语言按 `企划\10`；事实按 `企划\11` 速查卡

## 一、场景边界
- 课前（接笔记本、开爬塔）→ 上课（被点名讲原理 → 紧张轻伏笔）→ 下课（加好友、约联机）
- 核心事件：认识烫烫烫（同桌）+ 爬塔牵线 + 轻伏笔，一场全放

## 二、关键设定（用户确认 2026-08-05）
- **物理实验课**：两人一组合作；**烫烫烫 = 男主同桌/实验搭档**
- **课件 = PDF 文档**（不是没有课件）
- **双机分工 = 当场协商**：两台电脑各属于同桌两人，谁连器材/谁看文档要**在课前商量**（「你连器材还是看文档？」「我连器材。你那台看 PDF。」）→ 之后才有自然交互时间（你读文档，我调器材）
- **同桌看到屏幕很自然**：一桌就两个人、是一个小组，她瞥到男主玩塔不需要额外理由
- **课前玩塔**：男主上课前在笔记本上开爬塔；被同桌烫烫烫发现；说「牌序」不说「牌运」
- **设备 = 笔记本**：因为笔记本要连物理实验器材（数据采集器等）
- **紧张伏笔**：老师点名「第三组，烫烫烫，说说实验原理」→ 她紧张：声音变细、磕巴，耳尖动了一下 → 男主以为看错，不点破；全形态昆尼卡留到后面
- **结尾钩子 = LaTeX 合作**：这课要交的文稿有格式要求（LaTeX）；**烫烫烫是 LaTeX 高手、擅长用 AI**，教男主用 AI 排格式，合作交文稿；同时加好友
- **结算句 = 「这课，有点意思」**：不说「难熬」——这课有意思、器材先进

## 三、场景 3 序破急
- **序（低）**：课前。男主坐实验台前，接好笔记本数据线，开了一局爬塔（「十分钟，够打一层」）
- **破（升）**：
  1. 同桌烫烫烫凑过来（游戏宅雷达）：「你也玩？」→ 聊起来（几进阶/牌序）→ 认识落地，男主语言自然、无口头禅
  2. 上课后老师点名：「第三组，烫烫烫，说说这个实验的原理」→ 她紧张：声音变细、磕巴；男主余光瞥到耳尖动了一下（以为自己看错）——轻伏笔
- **急（顶 + 变）**：下课收拾器材，她先开口「加个好友。下次一起打塔。」→ 加好友成功；男主心理「这课，好像也没那么难熬」——微妙变化：同桌变成了认识的人，游戏群伏笔已埋

## 四、写法约束
- 剧本格式规范 v1 + 文风基准 + 人类逻辑提示词
- 男主语言自然、无固定口头禅；烫烫烫短句定调（绷/兑/乐）、游戏宅腔；昆尼卡伏笔只露「耳尖动」
