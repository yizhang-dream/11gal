# 企划 15：场景 05（走廊脚步声案）设计定稿

## 一、场景边界
- 深夜 H3 蹲点（查不出）→ CBT 思维宫殿推理 → 锁定洗衣房 → 靠近听到「脚步声」→ 男主开门 → 滴水 → 结案

## 二、关键设定（用户确认 2026-08-05）
- **蹲点查不出**：深夜 H3 走廊蹲了一会儿，什么都没有
- **CBT「思维宫殿法」**：她不用目击者画图，自己把路线图理出来，一句句推理：
  1. 电梯不可能（他不会在电梯里听到走廊脚步声）
  2. 寝室不可能（室友都在）
  3. **走廊没有窗户 → 外部也不可能**
  4. 最后锁定：嫌疑人只能藏在**洗衣房**
- **靠近洗衣房真的听到「脚步声」**（其实后文揭晓是滴水声）→ 两人害怕
- **男主热血名场面**：「社长大人别怕，我先上。」→ 挥随身带的**平板电脑**当武器 → 推门 → 没人 → **水龙头没拧紧在滴水**
- 结案：第二件委托，结案！

## 三、小序破急
- **小序**：深夜 H3 走廊碰头蹲点，十分钟，什么都没有
- **小破**：CBT 思维宫殿推理（一句句排除）→ 锁定洗衣房 → 靠近时真的听到「脚步声」→ 害怕 → 男主先上开门
- **小急**：没人，是滴水声 → 查清（普通解释）→ 结案；男主自嘲「我刚才是不是有点丢人」→ 心理落点：和她一起，好像什么都能查明白
