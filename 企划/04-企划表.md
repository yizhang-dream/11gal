# 企划表（主题 / 目的 / 故事推导）

> 本文档回答「这个游戏要做什么、为什么这么做」：策划书要点、主题、故事推导链、序破急充实、引子。
> 术语见 `99-术语表.md`；剧情细节见 `03-第一部-结构.md`。

## 一、策划书要点

- 游戏标题：**11gal（十一）**
- 游戏主旨：校园恋爱 + 怪谈解谜 + SCP 世界观；日常搞笑为主，超自然认真，结尾可刺激。
- 系统概述：**线性叙事为主**；第一部不做分支，或仅做不影响后续的「无意义小选项」（如课上回答/不回答，快速收束回主线）；通过群聊投稿/线索板推进叙事。
- 目标用户：**Galgame 玩家为主** + 熟人向（角色原型也会玩，取材梗作彩蛋）。
- 画面整体感觉：**半写实**——背景用学校真实拍摄图（需处理），人物二次元风格；不同场景风格可不同。
- 游戏目的（第一部）：调查真相 + 谈恋爱双线并行。
- 主人公：西湖大学 2026 级新生（玩家自选 ID）；路痴、爱游戏、创新/开拓精神、轻度社恐。
- 主要角色：CBT（第一部女主）+ 10 位已知真相的学生（见 `02-角色池.md`）。

## 二、主题

- 主题（抽象词/长句）：**好奇心与探索**——两个普通人凭好奇与努力探索真相，最终凭努力得到认可。
- 与游戏目的的挂钩：查案推进 = 好奇心驱动；结局「加入研究所」 = 被认可（目的=主题的原因）。
- 是否足以创作故事：是（已支撑完整事件链）。

## 三、故事：自问自答推导链（草案，待确认）

1. 为什么两个普通人会组侦探社？——因为 CBT 发起（明=查校园怪谈，暗=借侦探社探索自己身世——苏醒于入学前、大一一年没查清），只有男主加入（招新失败=侦探社冷清）。
2. 为什么他们会去查怪事？——因为好奇心 + 好友受害（HAL 被番茄砸中）启动番茄案（第一个熟人委托）。
3. 为什么查不出真相？——因为他们一直用「人为」框架（恶作剧/病毒/跟踪者），真相是超自然。
4. 为什么校园有超自然？——因为学校其实是基金会研究组织（研究所选址：087 本就在西湖大学）；侦探社在 087 之前先黑进内网发现「学校有秘密超自然研究」，但不知道是基金会。
5. 为什么已知真相的学生没能提前解决？——出手需要时间：低危事件优先级低、需确认与调度；最终 Raven（372 正面接触+警告）/ AutoMattic（1471 补最后一刀）/ 文件夹（087 救场）都出手了；372 本体由研究所收容处理（二次选拔是独立事实：解释学校为何观察学生、不强清记忆，不承担「为何不出手」的解释）。
6. 为什么两个普通人敢深入 087？——因为已经嗅到学校秘密（黑内网泄露 + Raven 神秘对话 + 文件夹 ID），F11 的门可能是答案。
7. 为什么最后能被认可？——因为两个普通人凭努力查到了 087，证明了价值 → 加入、编外小组。
8. CBT 的身世怎么收？——大结局加入后放开权限，查到当年入学时与「蛇之手」的通信记录（钩子）；完整身世来源放后日谈。

## 四、情节（定稿）

## 五、序破急充实（约 1 张 A4）

- **序（开端）**：序章（宿舍·回想）+ 招新现场 + 侦探社成立 + 学习日常（物理实验课同桌/爬塔联机/图书馆）。
- **破（高潮之前）**：前两案（快递柜/走廊脚步声，查清）→ 爬塔联机（津月镜新人物）→ 番茄案（断/挂起）→ 火锅聚餐（HAL 线下初见、Pixel 量子力学劝退）→ 1471（半断有获：追到内网深处 + AutoMattic 补刀 + 唯一一次「无需侦查」通知=催化剂）→ 文件夹甜食分享（日常穿插）→ 372（怀疑自己 → 图书馆检索电脑被 Raven 操控（黑客弹窗：F11 警告）→ 图书馆电子锁房偷听（神秘学姐））→ CBT 主动黑内网（发现学校秘密：文件夹 ID + Raven 实例）→ F11 门。
- **急（高潮+结局）**：087 深入（CBT 哥特服=动真格信号）→ 恐惧中表白 → 文件夹救场封印（黑内网「文件夹 ID」悬念闭环；损耗演出）→ 解释四案 → 摊牌（学校=基金会研究所；图书馆神秘对话=gdgfty×Raven；暑假 GOC 进攻背景）→ 加入 → 摊牌会议室（所有已知真相学生身份揭晓，CBT「奥斯卡影帝」）→ gdgfty 电子锁房间交接 → 放开权限 → 蛇之手通信记录（录取通知书+涂黑推荐函，CBT 身世钩子）→ 编外小组 + 清除普通学生记忆。

## 六、引子（游戏开头）

开场场景：**序章**（宿舍深夜：爬塔复盘 → 报考理由/气质相符 → SCP-1230 回想 → 刷到招新帖）→ **场景 1**（QQ 频道招新帖 → 回复 → 私聊 → 想退被挽留 → 入社）——先立人物与好奇心，再亮出侦探社玩法。

## 七、主题表现方式（不写进台词）

- 通过角色选择与行为：他们查下去了（明知查不出仍追）；男主/CBT 在 087 前选择继续深入。
- 通过故事发展：四案全部挂起仍不放弃 → 最终被认可（加入 = 被认可的具体表现）。
