# 场景 04（快递柜案）设计定稿

> 本文档是第一部前两案的第一案设计定稿：男主和 CBT 第一次线下见面，查清一件「快递不见了」的怪事（普通解释）。
> 相关：`10` 语言风格、`11` 速查卡、`13` 节奏、`99` 术语表。

## 一、场景边界

- 线上商议 → H3 门口初见 → 去 H5 → 查快递柜 → 结案 → 约深夜。

## 二、关键设定（2026-08-05 确认）

- **见面地点 = H3 宿舍楼门口**（男主住 H3）。
- **快递柜 = H5 地下一层**（不是生活环）。
- **H5 认知差**：男主以为 H5 是前面的食堂、地下一层要走楼梯；CBT 叫住他：「不用走楼梯，食堂后面有电梯」→ 带路绕了两绕。
- **初见三要素**：
  1. CBT 外貌：白毛萝莉红瞳（白发、红瞳、身形小）、普通卫衣。
  2. 男主脑补「社长 = 戴眼镜的男学长」→ 到约定地点老实等着、左右张望找人，不开口问女生。
  3. CBT 先开口：「不好意思，你是不是不认识我长什么样？」「你的社长就是我」——男主觉得好看，但没想到学姐居然是小萝莉（白毛红瞳）。
- **男主状态**：害羞、没和女生单独相处的经验 → 急着往前走（走快点就不尴尬了）。
- **CBT 线下**：拘谨（声音小一截、话少）但做事的热情在（带路利落、查案认真、拍照结案、主动约下一步）。
- **查案过程（节奏放缓）**：柜号 = 803-1（不会马上知道在哪，要沿柜子找过去）→ 开放格没有门，堆着好多快递箱 → 按投稿人描述（薄快递袋）逐件比对 → 查完一圈确实不是 → CBT 提议去别的位置找（可能快递员放错柜子）→ 正要转身走，男主感觉中间最大的箱子位置有点偏高 →「等等」→ 低头看 → 大箱子底下压着一个薄薄的快递袋 → 就是它（被压住看不见）→ 拍照确认 → 结案。

## 三、小序破急

- **小序**：线上商议（CBT 活力邀请「那两条委托！查不查！」）→ H3 门口初见（脑补男学长→CBT 先开口→认人）。
- **小破**：出发去 H5（害羞快走→被叫住→电梯→绕两绕）→ 地下一层快递柜 → 大箱子压住 → 挪开发现没丢 → 确认结案。
- **小急**：结案（普通解释）→ 两人组的默契初步建立；约深夜查第二案（走廊脚步声）。

## 四、语言基调

- CBT 线上：活力、短句、感叹号（「查不查！」「就现在！」）。
- CBT 线下：声音小、话少、行动利落；「第一单，结案！」。
- CBT 台词节奏（方案 C）：按 style-cbt 语料混合节奏——短句开路、中长句解释（带「所以/但是」）、短收/感叹收尾；不全是短句。
- CBT 台词带逻辑：判断要给理由（为什么/因为所以），不写没解释的短句（如「深夜」要补「因为报案人就是半夜听到的」）。
- 男主：心理与行为一致（等、张望、快走、尴尬）；语言自然无口头禅。
