# 场景 01（序章 + 招新）设计定稿

> 本文档是第一部开场两段（序章 + 招新现场）的设计定稿，可据此写剧本。
> 相关：`99-术语表.md`、`10-语言风格设计-剧本用.md`、`11-角色速查卡.md`。

## 一、场景边界

- **序章（独立小章节）**：宿舍深夜 → 爬塔复盘 → 回想（报考理由 + SCP-1230）→ 刷到招新帖。
- **场景 1 后半（招新）**：帖子 → 回复 → 路人退 → 私聊 → 想退 → 挽留 → 进群成功。
- **场景 2（下一场景）**：群聊成立、群公告、社员 2 人（见 `09`）。

## 二、序章设定

| 项 | 内容 |
|---|---|
| 时间 | 九月开学第一周深夜（社团招新季；8 月报到的第一个月在回想里压缩带过） |
| 地点 | H3 单人寝 |
| 男主状态 | 精力旺盛醒着（不用 36 小时作息——那是暑假作息） |
| 开场 | 爬塔（Slay the Spire）：更新削掉一层虚弱 → 算好的完美局面破功 → 多掉血 → 不 SL（自己做的选择自己负责，一往无前） |
| 走神 | 报考理由（一两句）：分数合适 + 学校新 + 气质相符（他天生不走寻常路） |
| 回想 | SCP-1230：放学路上旧书店发现绿书 → 梦一句带过 → 第二天书消失/老板不记得 → 再找无果 |
| 回想（第一个月压缩） | 8 月报到 → 9 月：快闪「参加小组活动、听迎新音乐会、在学术环里迷路」 |
| 结尾 | 刷 QQ 频道 → 看到【招新】校园未解之谜调查部（钩子，接场景 1） |

## 三、报考理由（修正）

- 追查绿书**不是**报考理由；它只说明他天生不走寻常路。
- 西湖大学 = 自主招生新型学校，不是「分够了」——男主是运气好通过了选拔。
- 报考理由 = 西湖大学气质与他相符（新、不按常理出牌）。

## 四、岛（SCP-1230，官网条目）

- 放学路上旧书店发现（呼应官网「小书店发现、店主无持有记忆」）。
- 轻量两拍：发现 → 消失；做梦一句话带过（只记得很清楚，内容模糊）。
- 不演梦细节、不悲剧（不用官网 B████ 教授沉溺 200 年的设定）。
- 男主归因：「想不出答案，就搁下了」。

## 五、招新帖（定稿）

- 时间：9 月社团招新季（序章改 9 月后）。
- 标题：【招新】校园未解之谜调查部。
- 文案：你遇到过那种——说不清、道不明，但确实发生过的事吗？我们专门收集并调查这些。有意者回复本楼。
- 发帖人：CBT（CBT.свт，侦探社发起人，第一部女主）。
- 冷清表现：底下 2~3 条回复，问「是正经社团吗」「加学分吗」，得知不是后客气退出（「哦……那打扰了」「没学分就算了」）。

## 六、场景 1 后半流程（定稿）

1. 序章结尾刷到帖子，被标题钩住。
2. 楼里回复：「这个部门……都查些什么？」
3. CBT 楼内回：什么都查，只提之前解决过的小事（泳池预约满员却没人=系统 bug；教室多媒体晚上自己开=遥控器卡讲台缝被压住）——不预告四案。
4. 私聊弹窗；他聊起喜欢推理小说、玩剧本杀（信息在这里出现，不在楼里）。
5. CBT 告知：不是正经社团、没注册、地下组织、人不多 → 男主想退。
6. 挽留：用他刚说的话（喜欢推理/剧本杀）+「群里正好有几条委托，先看看，不感兴趣再走」。
7. 进群成功，场景结束；群聊成立放场景 2。

## 七、写法约束

- 剧本格式规范 v1；文风基准（不用手机推送开场、数字写实、心理活动全角括号短句、金句配额、每场结算句+钩子）。
- CBT 台词按 style-cbt（短句快节奏、有内容、不啰嗦；语气词适度）。
- 男主：情绪稳定、积极、自嘲式记账。
