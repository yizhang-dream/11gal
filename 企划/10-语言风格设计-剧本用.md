> 用法：写任何角色台词前，先看本表「辨识锚点 + 口癖」，再对照蒸馏档案校准

## 设计原则
1. **口癖必须有真实出处**旧从蒸馏档案高频词里选），本人看了觉得「像我会说的」；
2. **可爱化**：网络语/表情指令适度保留，但节奏放缓、句子稍完整、去掉粗口，让它能放进 galgame；
3. **一角色一锚点**：锚点 = 说话时最容易被记住的一个特征旧口癖/句式/节奏），全作不撞车；
4. **线上 ≠ 线下**：线上按蒸馏旧短句、口癖、无标点感）；线下更收敛旧口癖减半、句子完整、出现敬语/客气），部分角色有反差旧见各人「线下」列）。

## 口癖池与降频规则旧v2 新增，方案 3：口癖池 + 句式指纹 + 降频）

- **规则**：每人一口癖池旧3~4 词）+ 一句式指纹；口癖当**情绪标点**——一人一场最多 2~3 次，按语境轮换，绝不每句前缀；平时靠句式指纹区分
- 男主：池 = 无固定口癖；指纹 = 行为热血 + 自嘲式结算
- CBT：池 = 绷不住了 / 这对吗 / 但是·所以；指纹 = 判断前置 + 转折推进
- HAL：池 = 不是哥们 / 怒了 / ？？？；指纹 = 起手否定 + 问号三连旧线上）；线下冷幽默
- 烫烫烫：池 = 兑 / 绷 / 乐 / 环！；指纹 = 单字定调 + 短句给结论
- 津月镜：池 = 哦哦旧≤2 次/场，仅惊讶/认可）/ 好 / +1 / 这样啊；指纹 = 温和追问「然后呢？/怎么做到的？」
- Raven：池 = 为什么 / 但是；指纹 = 句尾未闭合「旧」+ 逻辑降级问句
- AutoMattic：池 = 什么？/ 为什么？/ 我随意 / 好诶 / 😋；指纹 = 连环好奇提问 + 轻盈短句
- tmrf：池 = 菜汪！/ 绷 / 哦 / 对的；指纹 = 最短句 + 表情指令文字化 + 引用补刀
- gdgfty：池 = 心情+8 / 压力反应↑ / 汪汪；指纹 = 现实转译游戏状态播报
- Pixel：池 = 哇袄 / 兑。/ ？ / 。。；指纹 = 电报一句一信息 + 标点当表情
- 文件夹：池 = 冒泡 / 潜水 / 表情三连；指纹 = 慢 + 自嘲金句
- cbwzb：池 = 难绷 / mol / 666 / 我要验牌；指纹 = 判断前置 + 数据直给

> 撞车判定改为「口癖池 + 句式指纹」双维度：两人即使偶尔用同一个词，指纹不同就不算撞。
