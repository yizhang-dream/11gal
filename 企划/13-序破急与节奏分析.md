# 企划 13：序破急与节奏分析（第一部）

> 用途：写作时始终知道「当前场景在整条节奏线的哪个位置」——写小序破急不忘大序破急，反之亦然。
> 来源：skill game-scenario-writing（序破急/场景序列）+ 用户 2026-08-05 确认。

## 一、什么是序破急（本项目口径）
- **大序破急** = 整部作品：序（开端）→ 破（高潮前的全部推进，约占 80%）→ 急（高潮+结局）。
- **小序破急** = 一个时间段/一个重点场景：自己按 序→破→急 写成完整的小故事。
- **嵌套关系（像登山）**：大序破急是整座山；每个山段（小序破急）有自己的起伏，终点汇向山顶（087）。写任何场景前先问：这段是整座山的哪一段？它自己怎么起、怎么升、怎么落？
- **收束规则**：每段小序破急的「急」都要留下一个「微妙变化」（关系/认知/状态变了），不是回到原点。

## 三、小序破急：破·段1「查前两案」（定稿 2026-08-05）

- **小序（低）**：白天物理实验课（认识烫烫烫，日常）→ 晚上 CBT 提起两条挂着的委托 → 商议：**先查快递柜（近、目标明确），走廊脚步声留到深夜蹲点**（需要时机、更渗人）。
- **小破（升：普通 → 渗人）**：
  1. **快递柜案**：H3 门口碰面（男主和 CBT 第一次线下见面）→ 经食堂后面的电梯到 **H5 地下一层快递柜** → 发现**有人快递「不见了」，其实是被更大的箱子压住、看不见** → 查清（普通解释）。
  2. **走廊脚步声案（升级）**：深夜 H3 蹲点查不出 → **CBT「思维宫殿法」**理出目击者取外卖路线，一句句推理：电梯不可能 → 寝室不可能 → 走廊没窗户所以外部不可能 → **锁定洗衣房** → 靠近洗衣房真的听到「脚步声」（害怕）→ 男主「社长大人别怕，我先上！」挥平板开门 → 没人 → **是水龙头没拧紧在滴水** → 查清（普通解释）。
- **小急（顶+变）**：两案查清，初战两连胜；深夜收尾，两人组从「两个人的群」变成「能一起查案的搭档」（默契/信任确立）。
- **节奏要点**：气氛从日常（快递柜）升到渗人（深夜走廊/洗衣房），但结果都是普通解释——「怪谈其实是日常」，为后面「查不出的真怪谈」做反差铺垫。

## 五、节奏原则（本作）

1. **先赢后输**：前两案查清（赢）→ 番茄/1471/372 查不出（输）→ 087 全部释放。破的「登山感」靠这个落差。
2. **日常与怪谈交替**：白天日常（物理实验课/爬塔联机/图书馆/音游）穿插在案件之间，作缓冲，也是角色引入的时机。
3. **查不出 ≠ 无事发生**：每段查不出都留干预（AutoMattic/Raven 出手、通知无需侦查），把悬念滚到结尾统一解释。
4. **两人关系是暗线**：每段小急都落一点关系变化（前两案=默契确立；番茄=第一次一起查熟人案；087=表白）。
5. **角色引入不抢戏**：序不加新角色；破里一个案子/一段日常带一个人，且由事件自然带出（HAL=受害者、烫烫烫=同桌、Pixel=搭话）。
6. **秘密分层揭晓**：侦探社先发现「学校有秘密超自然研究」（黑内网泄露，不知道是基金会）→ 087 摊牌才补全「基金会」全貌——不是空降设定。

## 七、双人互衬与演出（2026-08-05 用户确认）

1. 强项：CBT 的推理 + 男主的魄力；「急」要给足力道
